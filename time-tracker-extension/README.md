# מד זמן לפרויקטים (תוסף כרום)

התקנה:
1. פתחי `chrome://extensions`
2. הפעילי "מצב מפתח" (Developer mode)
3. "טען ללא אריזה" (Load unpacked) ובחרי את התיקייה `time-tracker-extension`
4. מומלץ לנעוץ את התוסף בסרגל הכלים.

שימוש: לחיצה על האייקון → שם פרויקט → "הפעלת טיימר". בסיום → "סיום טיימר".
הטיימר ממשיך לרוץ גם כשהחלונית סגורה. הנתונים נשמרים מקומית בדפדפן, ואפשר לייצא ל-CSV.
