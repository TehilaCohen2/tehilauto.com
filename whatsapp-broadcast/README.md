# אוטומציית רשימת תפוצה WhatsApp

Python טהור: gspread (גיליון), smtplib / imaplib (Gmail), APScheduler או cron (תזמון). בלי n8n / Make / Zapier.

| משימה | מתי (שעון ישראל) | פקודה | מה היא עושה |
|---|---|---|---|
| 1 סרטון | ראשון 09:00 | `task1` | בוחרת נושא פנוי וסגנון הכי ישן, כותבת תסריט למושן גרפיקס ללא קול, שולחת לאישור במייל ושומרת brief ב-`output/` |
| 2 פוסט | רביעי 09:00 | `task2` | כותבת פוסט (עד 5 שורות), שולחת במייל, מסמנת `נוצל=כן` + תאריך |
| 3 נושאים | מוצאי שבת 20:00 | `task3` | מציעה 5 נושאים (מייל עם `APPROVE`), ובדיקת תשובות (`approvals`, כל 3 שעות) מוסיפה את המאושרים לטאב פוסטים |

## הקמה
1. חשבון שירות Google עם Sheets + Drive API. את ה-JSON שומרים כ-`GOOGLE_SA_JSON`.
2. סיסמת אפליקציה ל-Gmail (`GMAIL_USER`, `GMAIL_APP_PASSWORD`; IMAP פעיל בחשבון). `MAIL_TO` ברירת מחדל: tehila21376@gmail.com.
3. `pip install -r requirements.txt` ואז `python setup_sheet.py` — יוצר את הגיליון "רשימת תפוצה WhatsApp" (4 טאבים), משתף עם המייל וטוען 15 פוסטים ו-6 סגנונות. אם יצירה בחשבון שירות נחסמת: פתחי גיליון ריק, שתפי עם חשבון השירות כעורך, והגדירי `SPREADSHEET_ID`.
4. תזמון, אחת משתי דרכים:
   - **ענן (מומלץ):** `.github/workflows/whatsapp-broadcast.yml`. Secrets: `GOOGLE_SA_JSON`, `BROADCAST_SPREADSHEET_ID`, `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `MAIL_TO`. מטפל בשעון קיץ/חורף.
   - **שרת קבוע:** `python scheduler.py` (APScheduler, אזור זמן Asia/Jerusalem).

## הערות
- טאבים נוספים מעבר לדרישה: `הצעות_ממתינות`, `מצב`. עמודות נוספות בפוסטים: `קטגוריה`, `תאריך סרטון` (כדי שפוסט וואטסאפ לא יחזור על נושא הסרטון של אותו שבוע). שורות לא נמחקות.
- **סרטון:** הרינדור עצמו נעשה בקלוד קוד עם הסקיל social-video-nadav (לא ניתן להריץ אותו מתוך cron). המשימה מכינה נושא, סגנון ותסריט ושולחת לאישור; אחרי אישור ורינדור מריצים `python broadcast.py video-done` שמעדכן את הסגנון. תסריט שנדחה: `video-cancel`.
- **נושאים:** בנק סופי ב-`topics_bank.py` (27 נושאי הצעה, כ-5 שבועות). כשהוא מתרוקן נשלח מייל התראה, ויש להוסיף נושאים.
- בדיקות: `pytest tests`.
